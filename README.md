字节跳动 **Doubao Seedance 2.5** 视频生成模型的提示词撰写指南全文，以及官方提示词优化技能 `sd25-pe` 的本地副本。用于在 Claude Code / Codex / WorkBuddy 等支持 Skills 的 Agent 里直接调优提示词。

## 指南内容概要

1. **总体介绍**：全模态典型能力清单（主体/运动/白模/风格/音频/宫格分镜/关键帧参考、首尾帧、编辑、延长、一键成片、无缝转场）
2. **任务使用说明**：有锁定（编辑、首尾帧、延长会锁定宽高比与时长）与无锁定（参考类任务）两类，含触发条件和参数要求
3. **素材输入建议**：硬上限（图 30 张 / 视频 10 段 / 音频 10 段 / 合计 50 份）与稳定性推荐范围
4. **提示词写作建议**
   - 基础写作：素材指代、一句话概述（主体+地点+事件+题材+运镜）、具体情节描述、结尾补充
   - 进阶写作：镜头语言、动作/表情描述、白模参考、多宫格分镜、关键帧参考
   - 编辑类、首尾帧、时间戳（整数秒）、负向控制（字幕/BGM/音效/对白）
5. **与 Seedance 2.0 的差异**：响应时间戳、支持多视图、0.4–2.5 任意宽高比、MOV 输出提升 V2V 画质
6. **常见问题**：14 个真实 badcase 与解法，每个都带优化前后对比 —— 美学风格漂移、情绪过度响应导致瞳孔发光、角色对应错误、文字拼写错误、字幕约束不生效、特殊格式 JPG 报错、编辑前后时长不一致、复杂任务不稳定、编辑宽高比效果差、指纹状纹理、BGM 约束不生效、音频翻译语种混淆、音频水波纹噪声
7. **提示词案例**：白模（粗/细粒度）、宫格分镜、关键帧、视频指令编辑、视频参考图编辑、音频编辑、视频延长、一键成片、无缝转场，全部为可直接复用的完整 prompt

## 技能使用方法

### 方式一：官方 CLI 安装（推荐，可自动更新）

```bash
npx --yes skills@latest add \
  "https://arkdocs.tos-cn-beijing.volces.com/skills/" \
  --skill sd25-pe \
  --yes
```

安装后在 Agent 对话框输入 `/sd25-pe + 你的提示词` 即可开始调优。

### 方式二：直接拷贝本仓库的 SKILL.md

把 `skills/sd25-pe/SKILL.md` 放到你所用 Agent 的用户级技能目录，例如：

- WorkBuddy / CodeBuddy：`~/.workbuddy/skills/sd25-pe/SKILL.md`
- Claude Code：`~/.claude/skills/sd25-pe/SKILL.md`

该文件是单文件技能，无 `references/`、`scripts/`、`assets/` 依赖。

## 技能做了什么

不是同义改写器，是一套强制工作流：

1. **11 条不可违反原则**：意图优先（不改人物数量/道具/因果/结局）、模板优先、素材逐份负责、用户映射优先、最少澄清、只写可提交内容、参数分离（画幅时长不进 Prompt）、不滥加约束、单一最佳版本、事实与观察分离、主体基数匹配
2. **输入状态判定**：纯文生 / 有引用但无素材 / 素材可读 / 当前 Agent 不可读，四种降级路径都不假装看过素材
3. **8 步核心流程**：建立故事合同 → 编译小说长文本 → 两遍素材盘点 → 建立职责与主体映射 → 置信度处理 → 选择唯一主任务 → 应用任务参数规则 → 套模板并净化
4. **画幅与时长兼容性闸门**：参考视频规格与目标画幅冲突时，路由到正确任务类型并加消歧声明
5. **模板库**：视频生成、带参考生成、视频编辑、声音编辑、向前/向后延长、首帧/首尾帧、多关键帧、宫格分镜、粗细粒度白模
6. **30+ 项输出自检**：交付前逐条核对，包括「未采用素材」必须逐个列出编号

## 注意

`SKILL.md` 开头带有一段「触发前的自升级」逻辑：每个会话首次触发时会执行 `npx --yes skills@latest update sd25-pe -y`，属 best-effort，失败仅打印一行降级提示并继续，不阻塞生成。如果你不想每次触发都联网，可自行删掉该段。

如果用的是**直接拷贝**方式（方式二），CLI 不认识这个手动放置的副本，`update` 会失败并走降级分支，此时需要更新就重新下载覆盖即可。
